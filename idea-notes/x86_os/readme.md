# Simple x86 Bootloader

A bare-metal x86 bootloader written in NASM to explore real-mode assembly, BIOS interrupts, and the x86 boot process. Tested with QEMU.

---

## Execution Result

<img src="https://github.com/ulsidae/dev_logs/blob/main/idea-notes/x86_os/XD.png" height="600"/>

> **Note:** This is a minimal bootloader experiment, not a full-fledged operating system.

This project explores the Intel x86 architecture, real-mode memory layout, and low-level BIOS interactions by implementing a minimal bootloader.
